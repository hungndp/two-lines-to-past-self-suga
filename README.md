Two lines to a past self: do not send the 2 a.m. text to the ex — lonely is not in love — and the reason it mattered, because that one unsent message is why the narrator woke up proud instead of apologizing. Running the program drops both lines into the make.fun output folder as UTF-8 text, ready for the gate's 1-to-280-character check.

## Run it

```sh
python3 main.py
```
